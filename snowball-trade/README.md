# 캡틴 스노우볼의 무역회사

‘마이펫의 이중생활’의 스노우볼과 함께 제주 당근 5톤을 뉴욕 하수구 아지트까지 수입하며 무역 실무 감각을 익히는 선택형 학습 게임입니다.
개인 학습·비공개 스터디용 팬 게임이며, 캐릭터 저작권은 Illumination·Universal에 있습니다. 금액·세율·운임은 게임용 가상 수치입니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 설치나 서버가 필요 없습니다.
진행 상황은 장이 시작될 때마다 브라우저에 저장되고, 시작 화면에서 이어할 수 있습니다.

## 플레이 방법

- 대사창(또는 Space·Enter)을 눌러 진행하고, 선택지가 나오면 하나를 고릅니다.
- 💰 **자금**: $10,000으로 시작합니다. 선택에 따라 비용이 나가고, 마지막에 당근을 팔아 정산합니다.
- 😡 **분노 게이지**: 엉뚱한 선택을 하면 오르고, 100이 되면 스노우볼이 대폭발해 수리비가 나갑니다.
- 🃏 **용어 카드**: 장면마다 무역 용어 카드를 얻습니다. 모두 23장이고, 상단 버튼으로 도감을 볼 수 있습니다.
- 선택 뒤에는 ‘포피 할아버지의 한 줄’로 핵심을 정리해 줍니다.
- 마지막 정산 화면에서 등급(S~C), 장부, 내 선택으로 본 무역 흐름을 보여줍니다.

## 장 구성

| 장 | 장면 | 배우는 것 |
|---|---|---|
| 1 | 하수구 비상회의 | 문의(Inquiry), 신용조회, 문의와 주문의 차이 |
| 2 | 오퍼가 도착했다 | Firm Offer, 승낙, Counter Offer |
| 3 | 인코텀즈 대작전 | EXW·FOB·CIF·DDP, 적하보험 ICC(A)/(B)/(C) |
| 4 | 냥냥은행의 클로이 | T/T 선불·선금+잔금·후불, 신용장(L/C) |
| 5 | 서류 틀린그림찾기 | 상업송장 대조, 신용장 하자(Discrepancy) |
| 6 | 노먼이 사라졌다! | B/L 원본, 디머리지, L/G, Surrender B/L |
| 7 | 세관 탐지견 렉스 | HS 코드, 식물검역증, FTA 원산지증명 |
| 8 | 폭풍우와 젖은 당근 | 위험 이전 시점, 보험 보상 범위, 클레임과 검정보고서 |
| 9 | 당근 파티와 정산 | 전체 흐름 복습 |

앞 장의 선택이 뒤 장으로 이어집니다. 예를 들어 3장의 인코텀즈와 보험 선택이 8장의 손해 처리 결과를 정하고, 5장에서 놓친 서류 오류는 7장 통관에서 비용으로 돌아옵니다.

## 장면 고치기·추가하기

모든 내용은 `index.html`의 `CHAPTERS` 배열에 있습니다. 각 장의 `steps`에 아래 단계를 순서대로 넣습니다.

```js
L('snow', '대사')                                   // 대사 한 줄
{ t: 'doc', title: '제목', html: '<p>서류</p>' }     // 서류 보여주기
{ t: 'choice', prompt: '질문', options: [{
    label: '선택지', sub: '설명',
    run: S => { pay('장부 항목', -100); mad(10); card('bl'); S.flags.x = 1; },
    res: [L('gid', '결과 대사')],
    lesson: '포피 할아버지의 한 줄',
    retry: true,                                     // 고른 뒤 남은 선택지로 다시 묻기
}] }
S => S.flags.x ? [L('pops', '갈림 대사')] : null      // 앞 선택에 따라 갈라지기
```

`pay(항목, 금액)`은 자금과 장부, `mad(숫자)`는 분노 게이지, `card(id)`는 `CARDS`에 있는 용어 카드를 줍니다.
