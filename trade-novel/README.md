# 김스낵 수출 일지

무역 실무를 배우는 학습용 비주얼 노벨입니다. 플레이어는 김 스낵을 수출하는 회사의 신입 무역 담당자가 되어, 미국 바이어와의 첫 수출 한 건을 문의부터 대금 회수까지 진행합니다.
회사명, 금액, 환율은 모두 가상입니다. AI를 쓰지 않고 브라우저만으로 무료로 동작합니다.

## 실행

- **가장 간단한 방법**: `index.html`을 더블클릭해 브라우저에서 엽니다.
- **음성 입력(🎤)까지 쓰려면**: 마이크는 `https://` 또는 `localhost` 주소에서만 켜집니다. 이 폴더에서 아래 명령을 실행하고 `http://localhost:8000`을 여세요.
  ```
  python3 -m http.server 8000
  ```
- 진행 상황은 브라우저에 자동으로 저장됩니다. 상단의 "처음부터 다시"를 누르면 초기화됩니다.
- 주소 뒤에 `?fast=1`을 붙이면 글자가 한 번에 나옵니다(테스트용).

## 플레이 방법

- 선택지 버튼은 없습니다. 캐릭터에게 하고 싶은 말이나 행동을 직접 씁니다.
- 캐릭터는 입력에 들어 있는 **핵심 단어**에 반응합니다. "서류 볼게요"보다 "C/I랑 P/L 중량을 대조할게요"처럼 구체적으로 말할수록 잘 통합니다.
- 막히면 **힌트** 버튼을 누르세요. **이 장면 마무리**를 누르면 지금까지 한 대화로 장면을 끝냅니다.
- 장면이 끝나면 해설, 상태 변화, 이 장면의 무역 사실이 나옵니다.
- 마지막 복기 화면에서 각 결말이 어떤 뒤 장면을 불렀는지, 어떤 사고를 피했는지 볼 수 있습니다.

## 캐릭터 이미지 넣기

`img/` 폴더에 `캐릭터id_표정.png` 이름으로 넣으면 자동으로 나옵니다. 인물별 표정 목록과 생성 프롬프트는 [`img/CHARACTERS.md`](img/CHARACTERS.md)에 있습니다.

- 표정 그림이 없으면 `캐릭터id_normal.png`를 씁니다. 그것도 없으면 색깔 도형이 나옵니다.
- 사칭 메일 장면도 Dana의 그림을 그대로 씁니다. 겉모습으로는 구별할 수 없다는 점이 학습 포인트입니다.

## 음성

- **🔈 읽어주기**: 브라우저 내장 음성으로 캐릭터 대사를 읽습니다. (괄호) 안 행동 묘사는 읽지 않습니다. 바이어는 영어 음성으로 읽습니다. 어떤 목소리가 나오는지는 OS에 설치된 음성에 따라 다릅니다.
- **🎤 말로 입력**: 크롬·엣지·사파리에서 동작합니다. 파이어폭스는 지원하지 않습니다.
- **⏸ 멈춤**: 글자 출력과 읽어주기를 멈춥니다.

## 코드 구조 (`index.html` 한 파일)

| 구역 | 내용 |
|---|---|
| 0. 스타일 | 화면 디자인 (밝은/어두운 테마, 휴대폰 대응) |
| 1. 장면 데이터 | `CHARACTERS`, `STAGES`, `SCENES` 배열, 대금회수 계산 `finance()` |
| 2. 진행자 | 상태값, `pickNext()`(다음 장면 고르기), `judge()`, `applyOutcome()` |
| 3. 대사 엔진 | `respond()` — AI 대신 키워드 규칙으로 캐릭터가 답한다 |
| 4. 음성 | `Voice.speak()`, `Voice.listen()` |
| 5. 화면 | 대화 기록, 아바타, 전환 화면, 복기 화면, 저장 |

### 다음 장면 고르는 규칙 (`pickNext`)

1. 수습되지 않은 사고가 있으면 짝이 되는 문 팀장 수습 장면(`resolves`)을 엽니다.
2. 없으면 `when` 조건이 맞는 사고 장면 중 `priority`가 가장 높은 것을 엽니다.
3. 그것도 없으면 현재 단계의 본편을 열고, 본편이 끝나면 단계를 넘깁니다. 본편이 없는 단계(운송중, 도착)는 전환 문구만 보여주고 넘깁니다.
4. 한 번 나온 장면은 다시 열지 않습니다. 단계가 "종료"가 되면 복기 화면으로 갑니다.

플래그는 `null`(아직 모름)로 시작합니다. 사고 장면의 `when`이 `=== false`를 볼 때는, 그 플래그를 정하는 본편이 끝난 뒤에만 열립니다.

### 대처에 따라 갈라지는 경로

| 앞 장면에서 한 일 | 뒤에 생기는 일 |
|---|---|
| 견적에 유효기간을 안 넣음 | 운임 인상 뒤 옛 가격 요구 → 수습 |
| Marcus에게 등록비 송금 | 사기 → 수습 |
| 공장 출고일을 확인하지 않고 예약 | 배를 놓침 → 수습 |
| 서류 세 장을 대조하지 않음 | 미국 세관 통관 보류 → 수습 |
| 라벨 알레르기 표기를 놓침 | FDA 통관 거부 → 수습 |
| 신용장인데 송장 품명을 신용장 문구와 대조하지 않음 | 은행 "하자입니다" → 수습 |
| 선적 후 지급 조건 | 잔금 전 서렌더 요구 (첫 메일에서 바이어를 확인하지 않았으면 사칭 메일) |
| 입금 확인 전 서렌더 | 잔금 미입금 → 수습 |

## 장면 추가하기

`SCENES` 배열에 객체 하나를 넣으면 게임에 들어갑니다. 진행자 코드는 고칠 필요가 없습니다.

```js
{
  id: 'i_example', title: '장면 제목', type: '사고',      // '본편' | '사고' | '수습'
  character: 'han',                                        // CHARACTERS의 id (또는 st => id)
  when: st => st.flags.docsCrossChecked === false && st.stage === '도착',
  priority: 30,
  cause: ['docsCrossChecked'],                             // 복기 화면 연결용: 이 장면을 부른 플래그
  avoided: st => st.flags.docsCrossChecked === true,       // 복기 화면 "피한 사고" 판정
  avoidNote: '서류를 대조해서 이 사고를 피했다.',
  transition: '3일 뒤',
  situation: '화면에 보여줄 상황 설명',
  opening: L('angry', '(표정·행동) 첫 대사'),               // L(표정, 대사, { sub: 번역 })
  facts: ['이 장면에서 지켜야 할 무역 사실'],
  hidden: '캐릭터가 먼저 밝히지 않는 사실',
  goal: '학습 목표',
  hints: ['힌트 1', '힌트 2'],
  rules: [                                                 // 위에서부터 처음 맞는 규칙 하나로 답한다
    { id: 'fix', m: ['정정', '수정'], set: { fixed: true }, say: L('approve', '그래, 고쳐.') },
    { id: 'end', m: ['보고'], end: true, say: L('normal', '팀장님한테 가자.') },
  ],
  fallback: [L('question', '그래서?')],                    // 아무 규칙에도 안 맞을 때
  timeout: L('normal', '됐어.'),                           // 발언 9번이 넘거나 "마무리"를 누를 때
  outcomes: [                                              // 위에서부터 test가 참인 첫 결말
    { key: 'good', description: '고쳤다', test: ss => ss.c.fixed,
      meterDelta: { 팀신뢰: +1 }, learned: [{ term: '용어', desc: '설명' }], review: '해설' },
    { key: 'bad', description: '못 고쳤다', neutral: true,
      addIncident: { id: 'example', title: '사고 이름' }, review: '해설' },
  ],
}
```

규칙(`rules`)에서 쓸 수 있는 것:

| 필드 | 뜻 |
|---|---|
| `m` | 이 중 하나라도 입력에 있으면 맞음 (공백·쉼표 무시, 정규식 가능) |
| `all` | `[[...], [...]]` 각 묶음에서 하나씩 모두 있어야 맞음 |
| `not` | 이 중 하나라도 있으면 안 맞음 (예: 부정 표현 `NEG`) |
| `pending` | 직전에 캐릭터가 `ask`로 던진 질문에 대한 답일 때만 |
| `need` | `(ss, st) => boolean` 추가 조건 |
| `set` | 장면 안 체크 항목 `ss.c`에 기록 |
| `ask` | 이 대사로 질문을 던졌음을 표시 (다음 입력에서 `pending`으로 받음) |
| `end` | 이 대사 뒤 장면 끝 |
| `once` | 기본 `true`. `false`면 같은 규칙이 여러 번 나올 수 있음 |

수습 장면은 `recovery({...})` 틀로 만들면 "지금 할 일 → 재발 방지" 흐름이 자동으로 붙습니다.
